# Update

1. Search for the canonical target before creating a new page.
2. Fetch latest content and last-edited timestamp.
3. Change only affected sections; preserve unrelated content.
4. For material corrections, retain history and mark old facts superseded instead of silently erasing them.
5. Add provenance and temporal context.
6. Add/repair native mentions and verify backlinks.
7. Re-read after update. Reconcile concurrent edits rather than overwrite.
8. If a fact may belong in the separate Career Asset Master, ask the user before syncing it there.
