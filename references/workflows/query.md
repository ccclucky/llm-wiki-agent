# Query

1. Read Agent Context Protocol/home navigation when needed.
2. Search using entities, concepts, aliases, and the user's question.
3. Retrieve relevant pages, not just search snippets.
4. Follow native page mentions/backlinks to connected evidence.
5. Distinguish source facts, user-confirmed facts, agent synthesis, hypotheses, and unknowns.
6. Answer with Notion page links and flag missing/stale evidence.
7. Save a synthesis only when asked or workspace policy permits it.
