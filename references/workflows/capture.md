# Capture / RAW

Trigger: save, capture, collect, or add material to the knowledge inbox.

1. Preserve supplied material fully when feasible. For URLs, fetch content only when tools allow; never invent inaccessible content.
2. Resolve RAW from workspace navigation/schema.
3. Search by source URL, stable ID, title, or content fingerprint.
4. If already captured, update only when new material adds information; otherwise report duplicate.
5. Create a pending RAW item with origin, captured date, title, and original content/attachment.
6. Return its Notion link and say it is pending ingestion, not yet part of the Wiki.
