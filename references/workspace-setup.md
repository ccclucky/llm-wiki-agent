# Workspace setup

This Skill works with an existing Notion workspace and must not create a new workspace.

1. User connects this Agent's Notion MCP and authorizes the existing CCLUCKY Knowledge OS.
2. Agent searches for the Knowledge OS home page and reads its Agent Context Protocol.
3. Agent discovers actual RAW and knowledge destinations from the workspace; never guess IDs.
4. Agent verifies search, retrieve, create/update, append-block, native page mention, and backlink capabilities.
5. If RAW is absent, ask permission to create a RAW database in the existing workspace. A regular Inbox page is only a temporary queue if the user accepts it.
6. Never request that users paste tokens into chat. Each Agent has its own authorization.

A useful RAW schema includes title, content/attachment, source URL/origin, captured date, processing status, stable source ID/fingerprint, and resulting source-page reference.
