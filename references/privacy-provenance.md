# Privacy and provenance

- This repository is public. Never put user-specific RAW material, Wiki pages, personal profile data, employer-internal documents, or private examples here.
- Never commit Notion API keys, OAuth tokens, cookies, passwords, private keys, or connection strings.
- Personal knowledge stays in the user's private Notion workspace.
- Public examples must be synthetic.
- Preserve source origin, capture date, event date when known, and evidence links.
- Distinguish direct user statements from agent interpretations.
- Never expose private source text in logs, errors, issues, examples, or fixtures.
