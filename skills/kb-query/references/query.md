# Knowledge query workflow

When the user asks what the wiki knows about a subject:

1. Search canonical Notion knowledge pages for the main subject, aliases, and related terms.
2. Read matching Entity, Concept, or Synthesis pages; do not answer from search snippets alone.
3. Follow native mentions/backlinks to relevant Sources, Projects, Concepts, and original Rows records.
4. Read enough source pages to support the answer. Prefer primary evidence and relevant dates; do not assume the most recently edited page is most authoritative.
5. Separate verified facts, user-reported statements, source claims, analysis, and hypotheses.
6. Cite/link the underlying Notion source pages where the client supports it. Prefer the source over a synthesis alone.
7. Save a new Synthesis only when the user asks to preserve the answer.

Rows is the original-material archive; processed knowledge pages are the default query layer. Use Rows when source verification or original context is needed.

Answer directly. State material evidence gaps or contradictions. Do not dump entire pages unless requested.
